# GRWAI prototype builder — Figma plugin

A tiny local Figma plugin that rebuilds the screenshot frames of the prototype file as **editable Figma layers** (real text, vector icons, fills, gradients, shadows) while keeping every clickable hotspot on top, so Present mode keeps working.

It runs entirely inside your Figma desktop app on the free (Starter) plan. Nothing leaves your machine, no MCP, no Claude.

## Run it (about 5 minutes)

1. Open the Figma **desktop** app (free download) and open the prototype file
   `https://www.figma.com/design/OR4dzHm2sl75IfdpftvpnS`. Stay on the **Prototype** page.
2. Menu → **Plugins → Development → Import plugin from manifest…** and choose
   `tools/proto/figma-plugin/manifest.json` from this repo.
3. Menu → **Plugins → Development → GRWAI prototype builder**.
   A toast shows progress per screen; the run takes roughly 1–3 minutes for the 21 remaining frames.
4. When it finishes it also moves the two shared library frames (**Image assets**, **Icon components**) into a labelled **Library** section on the right. Keep that section — every screen's image fills and icon instances reference it.
5. Open **Plugins → Development → Open console** if you want the per-screen summary.

Frames that are already editable are skipped, so it is safe to run again. To rebuild everything from scratch, set `const FORCE = true;` at the top of `code.js` and run it once more (the hidden "Reference screenshot" layer in each frame is kept, so you can always toggle it on to compare against the real app).

## What it does, exactly

`code.js` is generated by `node tools/proto/build-layers.js plugin`. It embeds, for all 49 screens, the layer tree that `extract.js` measured from the running web app (positions, text runs with font/size/colour/line-height/letter-spacing, per-side borders, radii, gradients, shadows, rotation, clipping). For each frame it:

- removes the old screenshot fill (kept as a hidden, locked reference layer at the bottom),
- creates frames/rectangles/text nodes with the measured styles (Playfair Display + Inter, both available in Figma),
- places **instances** of the icon components and **shared image fills** from the Library section,
- re-appends the `→ …` hotspot layers on top so the prototype wiring is untouched.

## Fonts

Playfair Display (Regular, Italic) and Inter (Regular, Medium, Semi Bold) — both are Google Fonts built into Figma. If a style is missing the builder falls back to Inter Regular for that run rather than failing.
